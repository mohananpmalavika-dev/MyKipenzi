## Partner Care Reminders 💊

### Overview

Set caring reminders for your partner to help them maintain healthy habits throughout the day.

### Features

#### Reminder Types

Built-in reminder types with bilingual support:

1. **Did you eat?** (ഭക്ഷണം കഴിച്ചോ?) 🍽️
   - Gentle meal reminders
   - Ensures partner doesn't skip meals

2. **Take your medicine** (മരുന്ന് കഴിക്കണം) 💊
   - Medication reminders
   - Health management support

3. **Drink water** (വെള്ളം കുടിക്കൂ) 💧
   - Hydration reminders
   - Wellness tracking

4. **Take a break** (ഒന്ന് വിശ്രമിക്കൂ) ☕
   - Rest reminders
   - Prevent burnout

5. **Time to sleep** (ഉറങ്ങാൻ സമയമായി) 🌙
   - Sleep schedule support
   - Better rest habits

6. **Time to exercise** (വ്യായാമം ചെയ്യാൻ സമയം) 💪
   - Fitness motivation
   - Active lifestyle

7. **Rest your eyes** (കണ്ണുകൾക്ക് വിശ്രമം) 👀
   - Screen break reminders
   - Eye health

#### Scheduling Options

- **Time of Day**: Set specific time (e.g., 9:00 AM)
- **Days of Week**: Select which days (weekdays, weekends, custom)
- **Custom Message**: Add personal touch to reminders
- **Active/Inactive**: Toggle reminders on/off

#### Completion Tracking

- Partner confirms when they complete the reminder
- Optional notes on completion
- Habit tracking and statistics
- Weekly/monthly completion rates

#### Statistics Dashboard

- Total active reminders
- Completions this week
- Habit streaks
- Completion trends over time
- Most completed reminder types

#### Motivational Quotes

Daily motivational quotes in both languages to encourage healthy habits:

- Health quotes
- Wellness quotes
- Motivation quotes
- Rest quotes

### User Guide

#### Creating a Reminder

1. Open Partner Care Reminders
2. Click "Create New"
3. Select reminder type
4. Set schedule time
5. Choose days of week
6. Add custom message (optional)
7. Save reminder

#### Receiving Reminders

1. Notifications arrive at scheduled time
2. View reminder with caring message
3. Complete the task
4. Mark as complete in app
5. Add optional note

#### Viewing Statistics

1. Open "Stats" tab
2. View completion history
3. See habit trends
4. Track weekly progress

### Best Practices

✅ **Do:**
- Set realistic reminders
- Use gentle, caring language
- Respect partner's autonomy
- Celebrate completion streaks
- Adjust schedule as needed

❌ **Don't:**
- Over-remind (max 3-4 per day)
- Use demanding language
- Make it feel like nagging
- Set conflicting reminder times

## Period Tracker & Partner Support 🩷

### Overview

Private period tracking with optional partner visibility and support features. Designed with privacy-first approach and empathy mode for partners.

### Features

#### Calendar View

- Visual period calendar
- Color-coded period days (red)
- Predicted periods (dashed purple)
- Current day highlight
- Month navigation
- Quick date selection

#### Cycle Tracking

- **Start Date**: Log period start
- **End Date**: Mark period end
- **Flow Intensity**:
  - Spotting 🔵
  - Light 🟠
  - Medium 🟡
  - Heavy 🔴
- **Cycle Notes**: Additional observations

#### Daily Symptom Logging

Track symptoms each day:

- **Cramps** 😣
- **Headache** 🤕
- **Bloating** 🎈
- **Fatigue** 😴
- **Mood Swings** 😊😢
- **Back Pain** 🔥
- **Nausea** 🤢

**Mood Level** (1-5):
- 1: Very Low
- 2: Low
- 3: Okay
- 4: Good
- 5: Great

**Pain Level** (0-10):
- 0: No pain
- 1-3: Mild
- 4-6: Moderate
- 7-10: Severe

#### Cycle Predictions

Based on tracked cycles, the app predicts:

- Next period start date
- Expected end date
- Confidence level (low/medium/high)
- Requires 3+ cycles for accuracy

#### Cycle Phases

Automatic phase detection:

1. **Menstrual Phase** (Days 1-5)
   - Active period
   - Heavy flow days

2. **Follicular Phase** (Days 1-14)
   - Post-period
   - Energy building

3. **Ovulation** (Days 13-16)
   - Peak fertility
   - High energy

4. **Luteal Phase** (Days 15-28)
   - Pre-PMS
   - Energy decline

5. **PMS Phase** (Days 22-28)
   - Pre-menstrual symptoms
   - Need extra care

#### Partner Support Hints

When enabled, partner receives caring hints based on cycle phase:

**Menstrual Phase:**
- "Be extra caring today 💕"
- "Chocolate time! 🍫"
- "Heating pad might help 🔥"
- "Give extra hugs today 🤗"

**PMS Phase:**
- "PMS alert: Be patient and understanding 😊"
- "Extra comfort food time 🍕"

**Ovulation:**
- "Energy levels are high! ⚡"

**Follicular:**
- "Great time for activities together 🎉"

### Privacy Controls

#### Privacy Settings

1. **Share with Partner**
   - Default: OFF
   - Controls calendar visibility
   - Partner cannot see details without permission

2. **Partner Hints Enabled**
   - Default: OFF
   - Requires "Share with Partner" to be ON
   - Gives caring suggestions only
   - No specific symptom details shared

3. **Data Encryption**
   - All cycle data encrypted at rest
   - Private by default
   - User controls all sharing

### User Guide

#### Setting Up

1. Open Period Tracker
2. Go to Settings
3. Set average cycle length (default: 28 days)
4. Set average period length (default: 5 days)
5. Configure privacy settings

#### Logging a Cycle

1. Open "Calendar" tab
2. Click "Start New Cycle"
3. Select start date
4. Choose flow intensity
5. Add notes (optional)
6. Save cycle

#### Daily Logging

1. Open "Daily Log" tab
2. Select date
3. Choose symptoms
4. Rate mood (1-5)
5. Rate pain (0-10)
6. Add notes
7. Save log

#### Ending a Cycle

1. Open Calendar
2. Click "End Current Cycle"
3. Confirms end date as today

#### Partner View (for Partner)

1. Ask partner to enable sharing
2. Open "Partner View" tab
3. See current phase
4. Read caring hints
5. Show support based on suggestions

### Best Practices

✅ **Do:**
- Track consistently for accurate predictions
- Log symptoms daily during period
- Update cycle settings as needed
- Discuss sharing preferences with partner
- Use hints as gentle guidance

❌ **Don't:**
- Share without user permission
- Pressure partner to enable sharing
- Dismiss symptoms or mood changes
- Expect perfect predictions immediately
- Share specific details without consent

Guided meditation sessions, synchronized breathing exercises, stress tracking, and gratitude journaling to find calm together.

   - 10 minutes
   - Practice together
   - Shared awareness

3. **Stress Release** 🌊
   - 7 minutes
   - Quick stress relief
   - Individual or paired

4. **Gratitude Moment** 🙏
   - 5 minutes
   - Reflect together
   - Appreciate each other

5. **Evening Calm** 🌙

```http
GET /api/wellness/care-reminders/types
```

**Response:**
```json
{
  "types": [
    {
      "id": 1,

      "name_en": "Did you eat?",
```

## Database Schema

### Tables Overview

```sql
-- Partner Care Reminders
care_reminder_types          -- Predefined reminder types
care_reminders              -- User-created reminders
care_reminder_completions   -- Completion tracking
care_motivational_quotes    -- Daily quotes

-- Period Tracker
period_settings             -- User cycle settings
period_cycles              -- Cycle tracking
period_daily_logs          -- Daily symptoms/mood
period_partner_hints       -- Phase-based hints

-- Stress Relief
meditation_templates       -- Meditation sessions
meditation_sessions       -- Session tracking
stress_check_ins         -- Stress logging
ambient_sounds           -- Calming sounds
gratitude_journal        -- Gratitude entries

-- Views
wellness_dashboard_stats -- Aggregated statistics
```

### Key Relationships

```
account (user)
  ├── care_reminders (creator_id)
  ├── care_reminders (recipient_id)
  ├── period_settings (user_id)
  ├── period_cycles (user_id)
  ├── meditation_sessions (initiator_id/partner_id)
  ├── stress_check_ins (user_id)
  └── gratitude_journal (user_id)
```

### Schema File

Full schema available in: `server/wellness-schema.sql`

To initialize:
```sql
psql -d mykinpenzi -f server/wellness-schema.sql
```

### Notification Integration

Add wellness notifications to your notification system:

```javascript
// Example: Scheduled reminder notifications
async function sendReminderNotification(reminder, recipient) {
  await sendPushNotification(recipient.id, {
    title: reminder.name_en,
    body: reminder.message_en,
    icon: reminder.icon,
    data: {
      type: 'care_reminder',
      reminderId: reminder.id
    }
  });
}

// Example: Period hint notifications
async function sendPeriodHint(hint, partnerId) {
  await sendPushNotification(partnerId, {
    title: 'Partner Care Hint',
    body: hint.hint_en,
    icon: '💕',
    data: {
      type: 'period_hint',
      phase: hint.cycle_phase
    }
  });
}
```

## Privacy & Security

### Data Protection

#### Encryption
- All wellness data encrypted at rest
- TLS encryption in transit
- Secure session management

#### Access Control
- Users can only access their own data
- Partner data requires explicit permission
- Role-based access for shared features

#### Data Isolation
- Period tracking data private by default
- Sharing requires opt-in
- Granular privacy controls

### Privacy Features

#### Period Tracker Privacy

1. **Default Private**: All data private unless explicitly shared
2. **Consent Required**: Partner hints require both settings enabled
3. **Limited Visibility**: Partner sees hints only, not raw data
4. **Revocable**: Can disable sharing anytime

#### Care Reminders Privacy

1. **Bilateral**: Both users must be in conversation
2. **Transparent**: Recipient sees who created reminder
3. **Controllable**: Can delete or disable anytime

#### Stress & Meditation Privacy

1. **Gratitude Sharing**: Optional per entry
2. **Session Privacy**: Solo sessions completely private
3. **Stats Privacy**: Only user sees their own stats

### GDPR Compliance

#### Data Rights

Users can:
- Export all wellness data
- Delete all wellness data
- Modify privacy settings
- Revoke partner access

#### Data Retention

- Active data: Retained while account active
- Deleted accounts: All wellness data removed
- Export format: JSON

#### Implementation

```sql
-- Export user wellness data
SELECT * FROM care_reminders WHERE creator_id = ? OR recipient_id = ?;
SELECT * FROM period_cycles WHERE user_id = ?;
SELECT * FROM meditation_sessions WHERE initiator_id = ? OR partner_id = ?;
-- ... etc

-- Delete user wellness data (cascade delete configured)
DELETE FROM care_reminders WHERE creator_id = ? OR recipient_id = ?;
DELETE FROM period_settings WHERE user_id = ?;
-- ... etc
```

## Troubleshooting

### Common Issues

#### 1. Reminders Not Sending

**Problem**: Reminders created but not receiving notifications

**Solutions**:
- Check reminder `is_active` status
- Verify scheduled time and days_of_week
- Ensure notification permissions enabled
- Check server notification scheduler running

#### 2. Period Predictions Inaccurate

**Problem**: Next period prediction is off

**Solutions**:
- Track at least 3 complete cycles
- Update cycle length in settings
- Ensure end dates are logged
- Check for irregular cycles (may need adjustment)

#### 3. Partner Can't See Hints

**Problem**: Partner hints not showing

**Solutions**:
- Verify `share_with_partner` is TRUE
- Enable `partner_hints_enabled`
- Ensure partner ID is correct
- Check conversation exists between users

#### 4. Meditation Sessions Not Completing

**Problem**: Sessions started but not recording completion

**Solutions**:
- Call complete endpoint explicitly
- Check session ID is valid
- Verify user is participant (initiator or partner)
- Ensure duration is recorded

### API Error Codes

| Code | Message | Solution |
|------|---------|----------|
| 401 | Not authenticated | Login required |
| 403 | No conversation with this user | Start conversation first |
| 404 | Reminder/Cycle/Session not found | Check ID exists |
| 400 | Missing required fields | Provide all required data |
| 409 | Duplicate entry | Check for existing record |
